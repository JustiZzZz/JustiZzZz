## Проекты

### SeeSay — AI-ассистент для умных очков
**2023 — настоящее время** • основатель, разработчик

- Backend на `FastAPI`: голосовой ассистент на LLM (OpenRouter) с потоковым ответом и параллельной «гонкой» запросов — первые слова примерно через 1 с; память диалога, анализ фото с камеры, веб-поиск, геолокация и маршруты, синтез речи, синхронный переводчик. 142 теста, деплой на Linux
- Разобрал BLE-протокол очков AIMB (пакеты, CRC-8, Opus-аудио, фото с камеры) и написал Android-приложение на Flutter / Kotlin: детекция речи (VAD), управление кнопками очков. Демо для AI ATOM GLOBAL EXPO 2026
- Первый прототип: Raspberry Pi + камера, распознавание объектов на YOLO, MediaPipe и OpenCV с озвучкой

### MTBank AI Transcription — речевая аналитика звонков
**Июль 2026**

- Прототип для контакт-центра банка: OpenWebUI Pipeline и REST API на общем сервисе анализа
- Распознавание речи на `faster-whisper` с нормализацией через ffmpeg, разметка «оператор / клиент», 4 LLM-агента (классификация, качество, compliance, резюме) на Qwen с проверкой Pydantic и запасным сценарием
- 75 тестов, замер WER / CER, Docker Compose, HTTPS-деплой (Caddy) на DigitalOcean

### Защита RFID-систем от атак на идентификатор метки
**2023 — 2025** • Национальный детский технопарк • 3 научные публикации

- Стенд на MFRC522 и Arduino, спроектированный резонансный усилитель (NI Multisim, плата в EasyEDA): дальность считывания выросла более чем в 6 раз — это доказало риск клонирования меток на расстоянии
- Программная защита меток Mifare Classic: сессионный ключ из шума антенны, перезаписываемый при каждом считывании, белый и чёрный списки UID, журнал сессий
